# Experience

## WonderFi

**Software Developer Co-op**  
Toronto, ON | Jan 2025 – Dec 2025

### Overview

During my co-op at WonderFi, I contributed to the development and maintenance of
production cryptocurrency trading applications. I worked across backend and frontend
systems, developing APIs, testing backend functionality, integrating new features,
debugging production issues, and contributing to production deployments.

### What I Did

#### Backend Development

- Developed and modified backend functionality for production cryptocurrency trading applications
- Built and integrated **GraphQL and REST APIs** to retrieve and serve application data
- Implemented API endpoints to support frontend features and user-facing functionality
- Worked with existing backend services and codebases to implement new endpoint
- Investigated and resolved backend service and API-related issues
- Worked with application data and backend services to support cryptocurrency trading workflows

#### API Testing

- Used **Postman** to test and validate backend APIs
- Tested API requests and responses during feature development and debugging
- Verified endpoint behavior and data returned from backend services
- Used API testing to identify and troubleshoot backend issues

#### A/B Testing

- Implemented and analyzed A/B testing experiments using **LaunchDarkly**
- Contributed to backend and frontend functionality supporting experimentation
- Contributed to an experiment associated with a **35% increase** in customers discovering and purchasing additional crypto assets

#### Cryptocurrency & Production Development

- Contributed to production cryptocurrency trading workflows including deposits, withdrawals, and asset trading
- Contributed to the integration and deployment of **BNB (Binance Coin)** support into the production application

#### Loyalty System

- Implemented backend components for a loyalty system
- Developed API endpoints to retrieve loyalty-related data
- Integrated backend APIs with frontend components to display loyalty information
- Worked within an existing production codebase to introduce the new functionality

#### Docker & Development Environment

- Used **Docker** during backend development and application workflows
- Worked with containerized services as part of the development environment
- Used Docker to help maintain a consistent local development and testing environment

#### Web & Mobile Development

- Contributed to the development and refactoring of web and mobile applications
- Improved existing code, UI components, and application functionality
- Connected frontend components with backend APIs and services

#### Code Review & Deployment

- Created and reviewed pull requests using **Git**
- Participated in code review and collaborative development workflows
- Contributed to production deployments using **ArgoCD**
- Worked through the development, testing, review, and release process for production applications

**Tools:** Postman, Jest, Docker, ArgoCD, LaunchDarkly, Git, GitHub
