## Engineering Capstone Project

### Modernization of the Collision Avoidance Detection System
**Status:** In Progress | September 2026 – April 2027
**Project Sponsor:** Canadian Space Agency (CSA)
**Focus Areas:** Cybersecurity · Full-Stack Development · Data Visualization · Software Engineering
**Project Status:** The project is currently in the research, requirements gathering, and system planning phase. Security requirements, system architecture, technology choices, and implementation priorities will be refined through discussions with the Canadian Space Agency and the faculty supervisor.

### Overview

This engineering capstone project, sponsored by the Canadian Space Agency (CSA), focuses on designing and developing a secure, web-based collision monitoring and analysis platform.

As the number of satellites and space debris continues to increase, reliable collision monitoring has become increasingly important. The project aims to help satellite operators identify, visualize, and analyze potential conjunction events while emphasizing data integrity, secure information processing, and system reliability.

A central focus of the project is to incorporate security by design, ensuring that security considerations are integrated throughout the system architecture and development lifecycle rather than added as an afterthought.

### Project Objective

The primary objective is to develop a secure, reliable, and user-friendly software system capable of retrieving, processing, and visualizing collision-related information from external data sources.

The proposed system aims to:

- Securely retrieve and process collision-related data, including Collision Data Messages (CDMs).
- Protect data integrity through validation and appropriate verification mechanisms.
- Design secure backend services and APIs for reliable communication between system components.
- Explore authentication and authorization mechanisms to control access to sensitive system functionality.
- Provide interactive visualizations of potential collision events.
- Allow users to filter and prioritize events based on configurable criteria.
- Support automated alerts when events meet user-defined conditions.
- Enable further analysis of conjunction events, including the potential impact of orbital maneuvers.

### Security Considerations

Security is a key consideration in the design and development of CADS. Because the platform may process operationally important collision-related information, protecting the reliability, integrity, and accessibility of that information is essential.

The project will investigate and incorporate appropriate security practices in the following areas:

#### Data Integrity and Validation

Validate incoming CDM data, identify malformed or inconsistent records, and explore mechanisms for detecting unauthorized data modifications.

#### Secure API and Backend Architecture

Design backend services with secure communication, input validation, controlled data access, and protection against common web application vulnerabilities.s

#### Authentication and Access Control

Evaluate authentication and role-based authorization mechanisms to ensure that users can access only the information and functionality permitted by their roles.

#### Secure Data Storage

Consider database access restrictions, encryption, and secure handling of stored collision-related information.

#### Security Testing and DevSecOps

Integrate security considerations into the development lifecycle through automated testing, dependency vulnerability scanning, secure code review, and continuous integration practices.

#### Auditability and System Reliability

Explore logging and monitoring mechanisms to support traceability, troubleshooting, and the detection of unexpected system behavior.

### Planned Features

#### Collision Data Retrieval

Retrieve, validate, and organize conjunction data from authorized external sources while maintaining reliable data handling practices.

#### Interactive Collision Visualization

Develop a web-based dashboard that presents collision probabilities, miss distances, times of closest approach, and other relevant conjunction information.

#### Configurable Alert System

Allow users to define conditions that trigger alerts for potential collision events. Possible notification channels include email, text messages, and file-based outputs.

#### Event Analysis

Provide tools for examining collision events, comparing relevant data, and exploring the potential effects of orbital maneuvers.
