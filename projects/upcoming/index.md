## Engineering Capstone Project

### Modernization of the Collision Avoidance Detection System

### Overview

This engineering capstone project is sponsored by the **Canadian Space Agency (CSA)**
and focuses on modernizing a collision avoidance detection system for objects in space.

As the number of satellites and other objects in orbit continues to increase,
the risk of accidental collisions becomes an important concern. The project aims
to provide satellite operators with accessible information to help them evaluate
potential collisions and take appropriate corrective action.

### Project Objective

The objective is to design and develop a **web-based software system** capable of
fetching information about potential collisions between space objects from an
online catalog.

The system will allow users to:

- Define criteria for information retrieved from the online catalog
- Configure criteria that trigger automatic alerts
- Receive alerts through channels such as email, text, or files
- View potential collision events through an intuitive interface
- Analyze characteristics of potential collision events
- Perform additional analysis, including evaluating the impact of different maneuvers

### Key Features

#### Collision Data Retrieval

The system will fetch information about potential collision events from an
online space-object catalog based on user-defined criteria.

#### Alert System

Users will be able to configure conditions that automatically generate alerts
when potential collision events meet specified criteria.

Possible notification methods include:

- Email
- Text messages
- File-based notifications

#### Collision Visualization

Potential collision events will be presented through an intuitive web interface,
allowing users to understand and evaluate the relevant information more easily.

#### Event Analysis

The system will provide tools for analyzing potential collision events and
evaluating possible outcomes, including the impact of different orbital maneuvers.
