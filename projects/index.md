## Automatic Plant Watering Machine

**Arduino · Java · Firmata4J · Princeton StdLib**

### Overview

An automated plant-watering system that monitors soil moisture and
automatically activates a water pump when the soil becomes too dry.

### How It Works

1. A soil-moisture sensor measures the moisture level of the soil
2. The Arduino reads the sensor's voltage values
3. The Java application receives the sensor data
4. The system determines whether watering is required
5. The water pump is activated when the soil moisture falls below the required level
6. Moisture levels are displayed through a live graph

### My Contribution

- Developed the control application using **Java and Firmata4J**
- Integrated a soil-moisture sensor with an Arduino UNO Grove board
- Implemented automatic water-pump control based on soil-moisture readings
- Processed sensor voltage readings to monitor changes in soil moisture
- Implemented a live moisture-level graph using Java and Princeton StdLib

### What I Learned

- How software can interact with physical hardware and sensors
- How to communicate with an Arduino using Java and Firmata4J
- How to process real-time sensor data
- How to use sensor readings to control physical components
- How to visualize real-time data using Java
- How hardware and software can work together as an integrated system

## Engineering Capstone Project

### Modernization of the Collision Avoidance Detection System

### Overview

This engineering capstone project is sponsored by the **Canadian Space Agency (CSA)**
and focuses on modernizing a collision avoidance detection system for objects in space.

As the number of satellites and other objects in orbit continues to increase,
the risk of accidental collisions becomes an important concern. The project aims
to provide satellite operators with accessible information to help them evaluate
potential collisions and take appropriate corrective action.

### Project Objective

The objective is to design and develop a **web-based software system** capable of
fetching information about potential collisions between space objects from an
online catalog.

The system will allow users to:

- Define criteria for information retrieved from the online catalog
- Configure criteria that trigger automatic alerts
- Receive alerts through channels such as email, text, or files
- View potential collision events through an intuitive interface
- Analyze characteristics of potential collision events
- Perform additional analysis, including evaluating the impact of different maneuvers

### Key Features

#### Collision Data Retrieval

The system will fetch information about potential collision events from an
online space-object catalog based on user-defined criteria.

#### Alert System

Users will be able to configure conditions that automatically generate alerts
when potential collision events meet specified criteria.

Possible notification methods include:

- Email
- Text messages
- File-based notifications

#### Collision Visualization

Potential collision events will be presented through an intuitive web interface,
allowing users to understand and evaluate the relevant information more easily.

#### Event Analysis

The system will provide tools for analyzing potential collision events and
evaluating possible outcomes, including the impact of different orbital maneuvers.

### What I Expect to Learn

- Developing a larger-scale engineering software system
- Designing and integrating backend and frontend components
- Working with external APIs and online data sources
- Processing and presenting complex technical data
- Building configurable notification and alert systems
- Applying software engineering practices throughout the development lifecycle
- Collaborating within a multidisciplinary engineering team
- Developing software for a real-world aerospace application
