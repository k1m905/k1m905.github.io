# Automatic Plant Watering Machine

**Arduino · Java · Firmata4J · Princeton StdLib**

### Overview

An automated plant-watering system that monitors soil moisture and
automatically activates a water pump when the soil becomes too dry.

### How It Works

1. A soil-moisture sensor measures the moisture level of the soil
2. The Arduino reads the sensor's voltage values
3. The Java application receives the sensor data
4. The system determines whether watering is required
5. The water pump is activated when the soil moisture falls below the required level
6. Moisture levels are displayed through a live graph
