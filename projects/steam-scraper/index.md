# Steam Game Discount Scraper

**Python · Flask · HTML**

### Overview

A web application that collects Steam game information and identifies games
that are currently available at a discount.

### Features

- Scrapes game information from Steam
- Identifies games with active discounts
- Displays game and pricing information through a web interface
- Exports scraped data to CSV files

### My Contribution

- Developed the web application using **Python and Flask**
- Implemented the game data scraping functionality
- Processed and organized scraped game information
- Implemented CSV data export for storing collected information
- Developed a dynamic Flask/HTML interface to display game and pricing data
