# Productivity App

**Java · JavaFX · JUnit · PostgreSQL · Git**

### Overview

A productivity application developed as a 6-person team project to help users
organize their tasks and improve productivity through time management and
progress tracking.

### Features

- To-do list for managing daily tasks
- Pomodoro timer for focused work sessions
- User authentication and persistent login
- Notes management
- Progress tracking
- Integrated music player

### My Contribution

- Led a 6-person development team throughout the project
- Implemented the user authentication system
- Implemented the PostgreSQL database for storing user registration data
- Integrated the database with the application to support persistent user login
- Participated in the complete software development process from requirements gathering to final testing
- Collaborated with team members using Git throughout development

### Software Development Lifecycle

I participated in the development process from the initial planning stage
through testing and final delivery.

**1. Requirements Gathering**
- Identified application requirements and user needs
- Defined the core features and functionality of the application

**2. Planning & Design**
- Planned application structure and development tasks
- Designed the database structure and application components
- Divided development tasks among team members

**3. Development**
- Implemented application features using Java and JavaFX
- Developed the authentication system
- Integrated PostgreSQL for persistent data storage
- Integrated different components developed by team members

**4. Testing**
- Developed and executed unit tests using JUnit
- Performed end-to-end testing across the application
- Tested interactions between different application components
- Identified unexpected behavior and functionality issues

**5. Bug Reporting & Debugging**
- Documented bugs identified during testing
- Reproduced issues to identify their causes
- Tracked bugs throughout the development process
- Implemented fixes and verified that the issues were resolved

**6. Final Testing & Validation**
- Performed final end-to-end testing after implementing fixes
- Verified that major application features worked together correctly
- Conducted regression testing to ensure fixes did not introduce new issues
